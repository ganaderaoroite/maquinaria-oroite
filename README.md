# Maquinaria Oroite

App para cargar los trabajos de maquinaria y las cargas de gasoil de **Ganadera Oroite — Estancia Riachito**.

Es de uso interno: funciona con un PIN que solo conoce el personal de la estancia. El PIN no está en este repositorio.

Se publica con GitHub Pages en `https://<usuario>.github.io/maquinaria-oroite/`.
